## 简介
* 工具通过屏蔽互斥体访问方式以最简单的方式解锁多开。
* 在已打开微信的情况下也可以用。
* 支持微信3、4，自动检测，如果2个版本都装了优先运行4
* 在工具内点打开微信？没必要！！！本工具启动完微信后，自己会退出，不会一直开着占内存，哪怕一点点。
* **本工具其实就是个启动器！仅20多kb**

## 使用
* 运行程序 = 打开微信
* 再运行程序 = 打开第二微信
* 再再运行程序 = 打开第三微信
* ...

**So Easy**

**哦对了，本工具使用.net4开发，WIN10及以上自带。**

## 问题
